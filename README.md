# YRlp Portfolio

My personal website and portfolio, designed in Figma and implemented by me. It
represents my work as Yousef Roshandel (YRlp), a Front-end
Developer and UI/UX Designer, and was one of my first projects after learning
Vue.js. The site was originally built with Nuxt 2, upgraded to Nuxt 3 after its
release, and has continued to evolve with the Nuxt ecosystem.

Website: https://yrlp.ir

## Development

```bash
# install dependencies
npm install

# start the development server
npm run dev

# build for production
npm run build

# preview the production build
npm run start

# generate the static site
npm run generate

# publish the generated site to GitHub Pages
npm run deploy
```

## Built with

- [Nuxt](https://nuxt.com/) — application framework and routing.
- [Vue.js](https://vuejs.org/) — component-based UI development.
- [GSAP](https://gsap.com/) — page and scroll animations.
- [Sass](https://sass-lang.com/) — maintainable responsive styling.
- [Nuxt i18n](https://i18n.nuxtjs.org/) — Persian and English localization.
- [Nuxt Sitemap](https://nuxtseo.com/docs/sitemap) — sitemap generation.
- [Nuxt Robots](https://nuxtseo.com/docs/robots) — crawler directives.
- [Font Awesome](https://fontawesome.com/) — interface icons.

## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Full Persian (Farsi) and English language support.
- Dark and light themes, with dark mode enabled by default.
- Portfolio projects, blog posts, skills, experience, and contact information.
